# النشر

الموقع ثابت بالكامل: ارفع محتويات المجلد كما هي إلى أي استضافة ثابتة. لا يحتاج خادماً أو قاعدة بيانات.

## الخيارات
- **GitHub Pages:** أنشئ مستودعاً وارفع الملفات في الجذر، ثم Settings ← Pages ← Deploy from branch.
- **Netlify / Cloudflare Pages / Vercel:** اسحب المجلد إلى لوحة التحكم، أو اربط المستودع. لا توجد أوامر بناء (Build command فارغ) والمجلد المنشور هو الجذر.
- **استضافة عادية (cPanel…):** ارفع المحتويات إلى `public_html`.

## بعد معرفة الرابط النهائي
أضف داخل `<head>` في `index.html`:

    <link rel="canonical" href="https://رابطك/">
    <meta property="og:url" content="https://رابطك/">

وغيّر `og:image` إلى رابط مطلق: `https://رابطك/assets/img/og.jpg`، كي تظهر معاينة المشاركة صحيحة في واتساب وتيك توك وغيرها. اختبر المعاينة بعد النشر.

## تحديث النسخة الثابتة (اختياري)
بعد تعديل `data/content.js`:

    node scripts/build.mjs

يعيد توليد HTML العربي داخل `index.html`، ويحدّث العنوان والوصف وJSON-LD. لا يلزم لتشغيل الموقع.

## استضافة الخطوط ذاتياً (اختياري)
1. نزّل ملفات `woff2` للخطين: IBM Plex Sans Arabic وInter.
2. ضعها في `assets/fonts/` وعرّفها بـ `@font-face` في أعلى `css/style.css`.
3. احذف سطر `<link>` الخاص بـ Google Fonts و`preconnect` من `index.html`.

## قائمة فحص قبل الإطلاق
- [ ] إضافة حسابات التواصل المتبقية وحسابات العمل.
- [ ] إضافة ملف السيرة الذاتية الأخير وتعبئة `contact.cv` (أو تركه فارغاً لإخفاء الزر).
- [ ] إضافة الأعمال الحقيقية إلى `works`.
- [ ] ضبط `og:url` و`og:image` و`canonical`.
- [ ] تجربة الموقع على هاتف حقيقي (iOS وAndroid) وعلى Safari.
- [ ] تجربة روابط واتساب والاتصال والبريد.
