# دليل تعديل المحتوى

كل المحتوى في ملف واحد: `data/content.js`. عدّله ثم أعد تحميل الصفحة، ولا تحتاج أي أداة بناء.
القاعدة العامة: **أي حقل فارغ (`''` أو `[]`) يُخفى مكانه تلقائياً** من الموقع.

## 1) الاسم والنصوص
داخل `ar` و`en` (لكل لغة كتلتها):
- `name` / `nameEn`: الاسم. الاسم المعتمد حالياً «علي ناظم محمد».
- `role`: المسمى المهني، ويُفصل بين أجزائه بـ ` · `.
- `tagline`: النبذة التسويقية في الواجهة الرئيسية.
- `tags`: وسوم التخصصات الصغيرة.
- `ui`: بقية نصوص الواجهة (عناوين الأقسام، الأزرار، فقرات «نبذة عني»…).

### تمييز الكلمات المهمة
داخل أي نص من `ui` أو `tagline` أو وصف الخدمة:
- `{{كلمة}}` ← تمييز بلون التيل مع خط عنبري متحرك.
- `[[كلمة]]` ← تمييز بلون العنبري الغامق.

مثال: `أحوّل فكرة علامتك إلى {{محتوى مرئي}} يبني [[الثقة]]`.
استخدمه باعتدال (2–3 مواضع في الفقرة) ولا تضعه على جمل كاملة.

## 2) وسائل التواصل
في `contact`:
| الحقل | الاستخدام |
|---|---|
| `phone`, `phoneDisplay`, `phoneIntl` | الهاتف (الدولية بلا + مثل `9647771313149`) ← يولّد روابط الاتصال وواتساب |
| `email` | البريد |
| `tiktok`, `instagram`, `facebook` | الحسابات الشخصية. الفارغ يُخفى. تُحذف عوامل التتبّع من الرابط تلقائياً |
| `cv` | مسار ملف السيرة الذاتية، مثل `assets/cv.pdf`. عند تعبئته يظهر زر «السيرة الذاتية» |
| `accounts` | حسابات العمل (انظر أدناه) |

### إضافة حساب عمل
    accounts: [
      { platform: 'instagram', url: 'https://instagram.com/اسم_الحساب',
        ar: { label: 'حساب الأعمال' }, en: { label: 'Business account' } },
      { platform: 'tiktok', url: 'https://www.tiktok.com/@اسم_الحساب',
        ar: { label: 'حساب تيك توك للأعمال' }, en: { label: 'Business TikTok' } }
    ]
المنصات المدعومة: `tiktok` `instagram` `facebook` `youtube` `telegram` `linkedin` `website`.
تظهر هذه الحسابات في قسم التواصل تحت عنوان «حسابات العمل».

## 3) الخدمات
مصفوفة `services`. لكل خدمة: `id` و`cat` (تصنيف الفلتر) و`icon` وكتلتان `ar`/`en` فيهما `title` و`desc` و`long` و`points`.
- **الصورة:** تُقرأ تلقائياً من `assets/services/<id>.svg`. لاستبدالها بصورة خاصة ضع الحقل `image: 'assets/services/اسم.webp'` (نسبة 16:10، ويُفضّل 1280×800).
- **الأيقونات المتاحة:** `camera` `film` `motion` `sparkles` `megaphone` `calendar` `bulb` `coin` `live` `code`.
- الخدمة الأخيرة تُعرض بعرض كامل تلقائياً عندما يكون عدد الخدمات 7 أو 4 أو 10 (الحالي 10، فتُعرض خدمة المواقع والتطبيقات بعرض كامل).

### الأسعار وزر الطلب
- **زر «اطلب الخدمة»** يظهر تلقائياً على كل خدمة ويفتح واتساب برسالة `waOrder` + اسم الخدمة (من `ui` في كل لغة).
- **جدول الأسعار:** أضف إلى الخدمة حقل `pricing` بالأرقام (بالدينار العراقي):
  - باقات عملات: `pricing: { type: 'coins', rows: [{ amount: 1000, price: 19000 }, …] }`
  - باقات بأسماء: `pricing: { type: 'tiers', tiers: [{ id, price, tone: 'vip' | 'gold', ar: { name, note }, en: { name, note } }] }`
- تظهر شارة «ابتداءً من» على البطاقة من أقل سعر تلقائياً، ولكل صف في النافذة زر «اطلب» برسالة جاهزة (`waCoins` / `waTier`).
- `extras` (داخل `ar`/`en`) أزرار «متوفر أيضاً» تفتح واتساب باسم الخدمة الإضافية.
- التصنيف الجديد `tiktok` معرّف في `serviceCats`.

## 4) معرض الأعمال
قسم «معرض الأعمال» مخفي حتى تضيف أول عنصر في `works`:

    {
      id: 'work-1',                       // فريد
      cat: 'photo',                       // photo | video | motion | ai | design
      service: 'photo',                   // id الخدمة المرتبطة (يظهر العمل في نافذتها)
      type: 'image',                      // أو 'video'
      src: 'assets/works/work-1.webp',    // الصورة أو الفيديو
      thumb: 'assets/works/work-1-thumb.webp',   // اختياري: مصغّرة أخف
      poster: '',                         // للفيديو: صورة الغلاف
      ratio: '4/5',                       // 4/5 للتصاميم، 9/16 للفيديو العمودي، 16/9، 1/1
      ar: { title: 'اسم المشروع', desc: 'وصف العمل', service: 'تصوير إعلاني' },
      en: { title: 'Project name', desc: 'Work description', service: 'Ad photography' }
    }

- ضع الملفات في `assets/works/`. الأفضل WebP للصور وMP4 (H.264) للفيديو.
- تُعرض الأعمال بنسبتها الأصلية دون قص. الفيديو لا يعمل تلقائياً ولا بالصوت.
- لا تضف نتائج رقمية (مبيعات، متابعين…) إلا إذا كانت بيانات حقيقية موثّقة.

## 5) الخبرة والدورات والتعليم
مصفوفات `experience` و`courses` و`education`. الأقسام تظهر عند أول عنصر. صيغة كل عنصر مكتوبة كتعليق داخل الملف. لا تضف أسعاراً أو مواعيد غير مؤكدة في الدورات.

## 6) الصورة الشخصية
`assets/img/portrait.webp` (للعرض) و`portrait.png` (لبيانات SEO). صورة مفرغة الخلفية بأبعاد 720×1037 مع هامش شفاف فوق الرأس. عند الاستبدال حافظ على الهامش العلوي كي لا يُقص الرأس، وعدّل `width`/`height` في `js/render.js` (حالياً 720×1037) (دالة `hero`) إن تغيّرت الأبعاد.

## 7) بعد التعديل
- افتح الموقع وجرّب النسختين العربية والإنجليزية.
- (اختياري) شغّل `node scripts/build.mjs` لتحديث النسخة الثابتة وبيانات SEO داخل `index.html`.
