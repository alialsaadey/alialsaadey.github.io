# نظام التصميم

مأخوذ من الهوية البصرية المرفقة (لوحة التيل والعنبري ونقشة القطرات والشيفرون). لم يُنقل أي شعار أو اسم تجاري منها.

## الألوان
| الاستخدام | القيمة | المتغير |
|---|---|---|
| التيل الأساسي (أزرار، عناوين فرعية، الخلفيات الداكنة) | `#0A7C82` | `--teal` |
| تيل عميق (العناوين، الشريط) | `#065D63` | `--teal-d` |
| تيل أعمق (التذييل، أسفل التدرجات) | `#04464B` | `--teal-x` |
| العنبري (الأزرار الثانوية، الأيقونات، الخطوط) | `#F4AF16` | `--amber` |
| عنبري فاتح (نصوص على الخلفيات الداكنة) | `#F8C142` | `--amber-l` |
| عنبري غامق (نصوص صغيرة على الفاتح — تباين مقروء) | `#8F5E00` | `--amber-t` |
| رمادي مائل للأخضر (أقسام بديلة) | `#EAF3F2` | `--mist` |
| خلفية الصفحة | `#F6F8F7` | `--bg` |
| النص | `#10282B` / `#476064` | `--ink` / `--muted` |

قواعد: التيل للبنية والعناصر الأساسية، والعنبري للتفاصيل والتركيز فقط (لا يُستخدم كخلفية كبيرة). لا تضع نصاً عنبرياً فاتحاً على خلفية بيضاء.

## الخطوط
- العربية: IBM Plex Sans Arabic (400/500/600/700).
- الإنجليزية والأرقام والروابط: Inter.
- العنوان الرئيسي `clamp(2.5rem, 5.8vw, 4.9rem)`، عناوين الأقسام `clamp(1.8rem, 3.8vw, 2.7rem)`، النص 17px (16.5 على الهاتف).

## المكوّنات
- **البطاقات:** أبيض، حد 1px بلون التيل الخفيف، نصف قطر 22px، ظل ناعم تيلي.
- **الأزرار:** كبسولة. `primary` تيل، `outline` بحد، `amber` للدعوة الأخيرة، `ghost` للأدوات. لمعة تمرّ عند التحويم.
- **وسوم/شرائح:** كبسولات صغيرة بيضاء بحد خفيف.
- **أيقونات الخدمات:** مجموعة خطية موحّدة (شبكة 24px، سماكة 1.7، أطراف دائرية) داخل مربع عنبري بحافة بيضاء.
- **صور الخدمات:** SVG بنسبة 16:10، خلفية تيل متدرجة + نقشة قطرات + شيفرون، وعناصر بيضاء وعنبرية.
- **الصورة الشخصية:** دائرة تيل بحافة عنبرية ونقشة، والرأس يبرز فوقها عبر `clip-path` يقص الجزء السفلي فقط.
- **تمييز الكلمات:** `<mark class="hl">` — لون التيل وخط عنبري يمتد عند الظهور.

## الحركة
| الحركة | التنفيذ |
|---|---|
| كشف الاسم كلمة كلمة | قناع `overflow:hidden` + `translateY` |
| ظهور تدريجي للأقسام | `IntersectionObserver` + `opacity/transform/blur` |
| الشريط المتحرك | `translateX` مستمر، يتوقف عند التحويم |
| شرائح عائمة حول الصورة | حركة طفو بطيئة |
| دوران الزخارف | 140 و220 ثانية للدورة |
| بقعة ضوء في بطاقات الخدمات | متغيّرات CSS يحدّثها المؤشر |
| شريط تقدّم التمرير | `scaleX` في أسفل شريط التنقل |
| الشبكة الخلفية | `canvas` خفيف، يتوقف خارج الشاشة أو عند إخفاء التبويب |

الاحترام: `prefers-reduced-motion` يوقف الحركات ويُبقي المحتوى ظاهراً؛ التفاعلات المرتبطة بالمؤشر معطّلة على اللمس؛ المحتوى ظاهر كاملاً عند تعطيل JavaScript.

## نقاط التوقف
`≥1024` سطح مكتب · `768–1023` تابلت (عمودان) · `≤767` هاتف (عمود واحد).
