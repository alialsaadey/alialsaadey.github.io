# موقع علي ناظم محمد الشخصي

موقع شخصي احترافي لمصوّر إعلانات ومونتير وصانع محتوى مرئي، مبني بـ HTML وCSS وJavaScript صرفة (بلا مكتبات)، بواجهة عربية RTL افتراضية ونسخة إنجليزية كاملة، وبهوية بصرية تيل + عنبري.

## التشغيل محلياً
الأفضل تشغيل خادم بسيط داخل المجلد ثم فتح العنوان:

    python3 -m http.server 8000
    # ثم افتح http://localhost:8000

يمكن أيضاً فتح `index.html` مباشرة، لكن بعض المتصفحات تقيّد ميزات معينة عند الفتح من ملف.

## هيكل المشروع
    index.html              الهيكل + بيانات SEO وJSON-LD
    data/content.js         كل المحتوى (نصوص، خدمات، أعمال، حسابات) — الملف الذي تعدّله
    js/render.js            يولّد أقسام الصفحة من المحتوى
    js/main.js              التفاعل: القائمة، اللغة، الفلاتر، النوافذ، الحركات
    css/style.css           التصميم والهوية البصرية
    assets/img/             الصورة الشخصية، الشعار، أيقونة الموقع، صورة المشاركة
    assets/services/        رسوم الخدمات العشر (SVG)
    assets/works/           ضع هنا صور وفيديوهات الأعمال (يُنشأ عند الحاجة)
    scripts/build.mjs       اختياري: يحدّث النسخة الثابتة وبيانات SEO
    docs/                   التوثيق التفصيلي

## ترتيب أقسام الصفحة
الواجهة الرئيسية ← شريط الخدمات المتحرك ← الخدمات ← معرض الأعمال* ← نبذة عني ← المهارات والأدوات ← الخبرة* ← الدورات* ← التعليم* ← التواصل ← التذييل.
(*) أقسام تظهر تلقائياً فور إضافة محتوى حقيقي لها، وتبقى مخفية قبل ذلك.
