# موقع علي الساعدي الشخصي

موقع ثابت (HTML + CSS + JavaScript) بلا مكتبات ثقيلة. اللغة الافتراضية العربية (RTL) مع نسخة إنجليزية كاملة.

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً بسيطاً داخل المجلد:
`python3 -m http.server 8000` ثم افتح http://localhost:8000
(بعض المتصفحات تُقيّد ميزات معينة عند الفتح من ملف مباشرة؛ الخادم هو الأفضل.)

## النشر
ارفع محتويات المجلد كما هي إلى أي استضافة ثابتة: GitHub Pages أو Netlify أو Cloudflare Pages أو استضافة عادية.
بعد معرفة رابط الموقع النهائي أضف في `index.html` داخل `<head>`:
`<meta property="og:url" content="https://رابطك">` وغيّر `og:image` إلى رابط مطلق (https://رابطك/assets/img/og.jpg) كي تظهر المعاينة صحيحة عند المشاركة.

## تعديل المحتوى
كل النصوص والخدمات والأعمال والروابط في ملف واحد: `data/content.js`. عدّله وأعد تحميل الصفحة، دون أي أداة بناء.
- **روابط التواصل:** املأ `instagram` و`tiktok` و`facebook` في قسم `contact`؛ كل رابط فارغ يُخفى.
- **السيرة الذاتية:** ضع مسار الملف في `contact.cv` (مثل `assets/cv.pdf`) فيظهر زر التحميل في الشريط.
- **الأعمال:** ضع الصور في `assets/works/` وأضف عنصراً لكل عمل في مصفوفة `works` (المثال داخل الملف). القسم مخفي حتى تضيف أول عمل.
  استخدم `ratio: '4/5'` للتصاميم و`'9/16'` للفيديو العمودي، وسيُعرض العمل بنسبته دون قص في النافذة.
- **الخبرة والدورات والتعليم:** أضف عناصر في `experience` و`courses` و`education`؛ تظهر الأقسام تلقائياً حين لا تكون فارغة.
- **الصورة الشخصية:** `assets/img/portrait.webp` (و`portrait.png` للبيانات المنظمة).

## اختياري: تحديث النسخة الثابتة
`node build.mjs` يعيد توليد HTML العربي داخل `index.html` مع بيانات SEO وJSON-LD من `content.js`، لتظهر نسخة كاملة حتى بدون JavaScript.

## الملفات
- `index.html` الهيكل · `css/style.css` التصميم · `js/render.js` توليد الأقسام · `js/main.js` التفاعل
- `data/content.js` المحتوى · `assets/img/` الصور والشعار
